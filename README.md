# El Niño Over the Years

Interactive D3 visualization of El Niño and La Niña events, built on CMIP6 AMIP (NCAR CESM2) climate model data. DSC 106 Project 3, UC San Diego.

**Team:** Adam Hamadene, Dawai Yu, Emiliano Franco, Justin James

## Data

CMIP6 `amip` experiment, NCAR CESM2, ensemble member `r1i1p1f1`, from the public Google Cloud bucket `gs://cmip6`.
AMIP runs are driven by **observed** sea surface temperatures, so real El Niño events appear in the right years. Precipitation is the model's **simulated** response to those ocean temperatures.

Variables: `Amon/ts` (surface temperature), `Amon/pr` (precipitation), `fx/sftlf` (land fraction).

## Repo layout

```
index.html, main.js, style.css     D3 visualization + write-up (served by GitHub Pages from the repo root)
data/                              static files the site reads (generated by the data prep notebook)
data/land.geojson                  coastlines for the map (Natural Earth 110m, via world-atlas)
exploratory/elnino_data_prep.ipynb pulls from Google Cloud, computes anomalies + Niño 3.4, exports data/
exploratory/export_climatology.ipynb exports data/climatology.json (1981–2010 monthly averages) and
                                   data/california.csv (California Nov–Mar rain per winter vs. ONI)
data/california.geojson            California outline (US Census via us-atlas)
exploratory/*.ipynb                the team's exploratory graphs and checkpoint notebook
environment.yml                    conda environment for the notebooks
```

## Regenerating the data

```bash
mamba env create -f environment.yml    # or: conda env create -f environment.yml
conda activate elnino
```

Open `exploratory/elnino_data_prep.ipynb` in VS Code, select the **elnino** kernel, and Run All. It writes into `data/` (~15 MB).

## Running the site locally

Use VS Code Live Server, or from the repo root:

```bash
python -m http.server 8000
```

then open http://localhost:8000. (Opening `index.html` directly blocks the data from loading.)
